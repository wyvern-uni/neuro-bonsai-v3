# 🌳 Neuro Bonsai V3

An interactive procedural bonsai tree simulation built with Python and Pygame, exploring neural networks, evolutionary algorithms, and organic growth.


This project explores how neural networks and evolutionary algorithms can influence procedural organic structures. It was developed as a personal Python learning project using help from sources such as ( The Nature of Code: Simulating Natural Systems with JavaScript and i did do it into python ), other source is AI ( chatGPT, claude, KIMI ) and some self learning.

**Note:** The trunk structure is predefined, while neural-network-driven recursive growth influences the side branches. The evolutionary system is experimental.
