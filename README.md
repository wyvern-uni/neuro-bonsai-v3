# 🌳 Neuro Bonsai V3

An interactive procedural bonsai tree simulation built with Python and Pygame, exploring neural networks, evolutionary algorithms, and organic growth.

## Features

- **Neural Network:** A feed-forward 6-6-3 neural network influences recursive branch growth.
- **Neuroevolution:** Experiments with Gaussian mutation and fitness-based selection.
- **Procedural Generation:** Creates organic branching structures.
- **Environmental Effects:** Includes seasons, wind, falling leaves, and snow.
- **Interactive Simulation:** Multiple bonsai styles, simulation speeds, and visualisation tools.

## Technologies

- Python
- Pygame
- Neural Networks
- Neuroevolution
- Recursion
- Procedural Generation

## Installation

Install the required dependency:

```bash
pip install pygame
```

Run the simulation:

```bash
python neuro_bonsai.py
```

## Controls

| Key | Action |
|---|---|
| SPACE | Pause / Resume |
| 1 / 2 / 3 | Simulation speed |
| N | Next generation |
| E | Evolve 60 generations |
| R | Reset lineage |
| T | Change tree style |
| M | Toggle neural network visualisation |
| ESC | Quit |

## About

This project explores how neural networks and evolutionary algorithms can influence procedural organic structures. It was developed as a personal Python learning project.

**Note:** The trunk structure is predefined, while neural-network-driven recursive growth influences the side branches. The evolutionary system is experimental.
